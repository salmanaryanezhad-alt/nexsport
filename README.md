# NexSport — برنامه‌ریز رایگان مسابقات (فاز ۱)

این پروژه پیاده‌سازی نسخه اول NexSport است: یک ابزار رایگان برای تولید برنامه
مسابقات، بدون نیاز به حساب کاربری یا دیتابیس، طبق سند اسپک پروژه.

## فرمت‌های پشتیبانی‌شده

- لیگ
- لیگ رفت و برگشت
- مرحله گروهی (با سیدبندی کاملاً اختیاری)
- گروهی + حذفی
- حذفی (با پشتیبانی از Bye برای تعداد تیم‌های نامتوازن)

## اجرای پروژه

پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر.

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

برای build نهایی:

```bash
npm run build
npm start
```

## ساختار پروژه

```
app/                  صفحات Next.js (App Router)
  page.tsx            صفحه اصلی
  planner/page.tsx     ویزارد ساخت برنامه مسابقات
components/planner/    کامپوننت‌های نمایش نتیجه و مراحل ویزارد
lib/scheduling/         موتور تولید برنامه (بدون وابستگی به UI)
  roundRobin.ts         موتور لیگ و لیگ رفت و برگشت (circle method)
  groups.ts              تقسیم گروه‌ها با سیدبندی اختیاری
  knockout.ts            موتور براکت حذفی با Bye و سیدبندی استاندارد
  index.ts                نقطه ورود + اعتبارسنجی ورودی‌ها
```

موتور برنامه‌ریزی (`lib/scheduling`) کاملاً مستقل از UI نوشته شده تا در آینده
(فاز ذخیره‌سازی، پنل باشگاه، پنل برگزارکننده و...) قابل استفاده مجدد باشد.

## نکات فنی

- **بدون بازی تکراری**: موتور لیگ از روش استاندارد Circle Method استفاده
  می‌کند که ریاضیاتاً تضمین می‌کند هیچ دو تیمی بیش از یک‌بار (یا در حالت
  رفت‌وبرگشت، دقیقاً دو بار) مقابل هم قرار نمی‌گیرند.
- **قرعه‌کشی تصادفی**: اگر برگزارکننده هیچ تیم شاخصی انتخاب نکند، توزیع
  تیم‌ها در گروه‌ها/براکت کاملاً تصادفی است (طبق بخش ۱۱ سند اسپک).
- **Validation**: قبل از تولید برنامه، ورودی‌ها بررسی می‌شوند (نام تکراری،
  تعداد گروه بیشتر از تعداد تیم، تعداد سرگروه بیشتر از تعداد گروه و...) و در
  صورت ناسازگاری پیام خطای فارسی نمایش داده می‌شود.
- **چاپ / PDF**: دکمه «چاپ / ذخیره PDF» از قابلیت چاپ مرورگر استفاده می‌کند
  (در دیالوگ چاپ می‌توان «Save as PDF» را انتخاب کرد)؛ فقط ناحیه نتیجه چاپ
  می‌شود.

## مراحل بعدی (طبق اسپک پروژه)

این پیاده‌سازی فقط فاز ۱ (برنامه‌ریز رایگان) را پوشش می‌دهد. فازهای بعدی طبق
سند اصلی شامل حساب کاربری، ذخیره برنامه‌ها، پنل باشگاه، پنل برگزارکننده،
اشتراک/Plus و پرداخت خواهند بود که در این نسخه پیاده‌سازی نشده‌اند.
