# NexSport — برنامه‌ریز مسابقات ورزشی (فاز ۱ پیشرفته)

این پروژه ابزار مدرن و سریع **NexSport** است: یک سیستم کامل برای قرعه‌کشی، برنامه‌ریزی مسابقات و مدیریت زنده نتایج و رده‌بندی بدون نیاز به دیتابیس یا حساب کاربری.

## فرمت‌های پشتیبانی‌شده

- **لیگ تک‌دور**: هر تیم یک بار با هر تیم دیگر (بر اساس الگوریتم Berger / Circle Method).
- **لیگ رفت و برگشت**: بازی خانگی و خارج از خانه با رعایت توازن میزبانی.
- **مرحله گروهی**: تقسیم خودکار تیم‌ها به گروه‌های متوازن با امکان سیدبندی اختیاری.
- **گروهی + حذفی (Crossover استاندارد)**: صعودکنندگان گروه‌ها با جدول ضربدری کلاسیک وارد براکت می‌شوند و تیم‌های هم‌گروه تا فینال به هم برخورد نمی‌کنند.
- **مرحله حذفی (Knockout Bracket)**: براکت حذفی استاندارد با پشتیبانی از استراحت (`Bye`) برای تعداد تیم‌های نامتوازن.

## ویژگی‌ها و امکانات جدید پیاده‌سازی شده

1. **ثبت زنده نتایج و گل‌ها (Live Match Scores):**
   - امکان ثبت گل‌های میزبان و میهمان برای تمامی مسابقات.
   - تعیین برنده در بازی‌های حذفی به همراه انتخاب دستی برنده (در صورت تساوی).

2. **جدول رده‌بندی زنده (Live Standings Table):**
   - محاسبه لحظه‌ای جدول بر اساس نتایج ثبت‌شده (بازی، برد، مساوی، باخت، گل زده، گل خورده، تفاضل گل و امتیاز).
   - نشانگر اختصاصی تیم‌های صعودکننده و قهرمان.

3. **صعود خودکار در براکت حذفی (Interactive Tournament Bracket):**
   - با وارد کردن نتایج هر بازی حذفی، تیم برنده به طور خودکار به جایگاه مسابقه دور بعد (نیمه‌نهایی / فینال) راه می‌یابد و در پایان، قهرمان تورنمنت معرفی می‌شود.

4. **قرعه‌کشی مجدد با یک کلیک (Re-draw / Shuffle):**
   - امکان ایجاد یک چینش کاملاً متفاوت و تصادفی جدید با همان تیم‌ها و تنظیمات، بدون نیاز به بازگشت به مراحل قبل.

5. **ذخیره‌سازی خودکار در مرورگر (LocalStorage Persistence):**
   - تمامی مراحل، اسامی تیم‌ها، تنظیمات و نتایج ثبت‌شده در مرورگر ذخیره می‌شوند تا با رفرش صفحه از بین نروند.
   - دکمه «شروع مسابقه جدید» برای بازنشانی کامل فرم.

6. **اشتراک‌گذاری در پیام‌رسان‌ها (Copy for Telegram / WhatsApp):**
   - دکمه کپی فوری متن خوانا و مرتب برنامه مسابقات همراه با ایموجی‌های ورزشی برای ارسال در گروه‌های تلگرام و واتس‌اپ.

7. **خروجی فایل اکسل استاندارد (CSV with UTF-8 BOM):**
   - دانلود مستقیم فایل اکسل با فونت و انکودینگ فارسی بدون به‌هم‌ریختگی حروف.

8. **چاپ بهینه و خروجی PDF:**
   - استایل اختصاصی برای چاپ بدون نمایش دکمه‌ها و عناصر اضافی رابط کاربری.

## اجرای پروژه

پیش‌نیاز: Node.js نسخه ۱۸ یا بالاتر.

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را در مرورگر باز کنید.

برای اجرای تست‌های واحد الگوریتم‌ها:

```bash
npm test
```

برای build نهایی:

```bash
npm run build
npm start
```

## ساختار پروژه

```
app/                      صفحات Next.js (App Router)
  page.tsx                صفحه اصلی و معرفی
  planner/page.tsx         ویزارد ۵ مرحله‌ای برنامه‌ریز با ذخیره‌سازی محلی
components/planner/        کامپوننت‌های رابط کاربری
  ScheduleView.tsx         نمایش تعاملی بازی‌ها، ثبت نتایج، جدول رده‌بندی و براکت درختی
  Stepper.tsx              نمایش مراحل ویزارد
lib/scheduling/             موتور محاسباتی و منطق مسابقات (کاملاً ماژولار و مستقل)
  roundRobin.ts            الگوریتم لیگ تک‌دور و رفت‌وبرگشت
  groups.ts                تقسیم و قرعه‌کشی گروه‌ها با سیدبندی
  knockout.ts              براکت حذفی، منطق Bye، جدول ضربدری و صعود برنده‌ها
  standings.ts             محاسبه جدول رده‌بندی و امتیازات بر اساس نتایج بازی‌ها
  export.ts                خروجی متن پیام‌رسان‌ها و اکسل (CSV UTF-8)
  types.ts                 تایپ‌های تایپ‌اسکریپت
  scheduling.test.ts       مجموعه ۳۱ تست واحد برای تمامی سناریوها
```
