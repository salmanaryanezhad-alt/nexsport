# راهنمای انتشار نکس‌اسپورت روی بازار و مایکت

اپ، پوستهٔ اندروید سایت **فاز ۲** روی `https://nexsport.ir` است. باشگاه و فازهای بعد داخل منو، متن فروشگاه و اسکرین‌شات‌ها نیست.

آپلود را فقط با **حساب توسعه‌دهندهٔ خودتان** انجام دهید؛ از اینجا نمی‌شود وارد پیشخان بازار یا مایکت شد.

## فایل‌هایی که لازم دارید

| فایل | مسیر |
| --- | --- |
| آیکون ۵۱۲ | `store-listing/icon-512.png` |
| بنر تبلیغاتی ۱۶:۹ | `store-listing/feature-graphic.jpg` |
| اسکرین‌شات‌ها | `screenshot-1-home.jpg` تا `screenshot-4-schedule.jpg` |
| متن بازار | `store-listing/bazaar-listing.txt` |
| متن مایکت | `store-listing/myket-listing.txt` |
| APK امضاشده | بعد از بیلد: `android-app/app/build/outputs/apk/release/app-release.apk` |
| کلید امضا | `android-app/nexsport-release.jks` — **این را گم نکنید** |

## ساخت APK روی کامپیوتر

۱. [Android Studio](https://developer.android.com/studio) را نصب کنید.  
۲. پوشهٔ `android-app` را Open کنید.  
۳. اگر `nexsport-release.jks` و `keystore.properties` کنار پروژه هست، `Build → Generate Signed Bundle / APK → APK → release` بزنید.  
۴. خروجی `app-release.apk` را در بازار و مایکت بارگذاری کنید.

اگر کلید را خودتان می‌سازید، همان را برای **هر دو فروشگاه** و همهٔ آپدیت‌های بعدی نگه دارید. بدون آن نمی‌شود نسخهٔ جدید همان اپ را جایگزین کرد.

## بازار (کافه بازار)

۱. پیشخان: https://pishkhan.cafebazaar.ir  
۲. حق اشتراک سالانه را در صورت نیاز تمدید کنید.  
۳. برنامهٔ جدید → بارگذاری APK.  
۴. عنوان: **نکس‌اسپورت**  
۵. آیکون ۵۱۲، حداقل ۴ اسکرین‌شات، در صورت امکان بنر ۱۶:۹.  
۶. متن را از `bazaar-listing.txt` کپی کنید.  
۷. دسته: ورزش. رایگان.  
۸. ایمیل/تلفن پشتیبانی خودتان.  
۹. درخواست انتشار.

بازار معمولاً چند روز کاری بررسی می‌کند.

## مایکت

۱. پنل توسعه‌دهندگان مایکت  
۲. برنامهٔ جدید → APK (همان فایل امضاشده)  
۳. نام، آیکون، اسکرین‌شات و متن `myket-listing.txt`  
۴. دستهٔ ورزش و تندرستی  
۵. ارسال برای بررسی

## نکات مهم فاز ۲

- آدرس داخل اپ ثابت است: `https://nexsport.ir` — نه Vercel.  
- هر تغییری که روی **سرور فاز ۲** بدهید، بدون آپدیت فروشگاه داخل اپ می‌آید.  
- تا وقتی این اپ روی فروشگاه است، **باشگاه و فاز ۳ را روی سرور نگذارید**؛ وگرنه همان‌ها در اپ دیده می‌شوند.  
- برای آپدیت فروشگاهی (آیکون، نسخه، منو) باید `versionCode` را در `android-app/app/build.gradle` یکی بالا ببرید و APK جدید با **همان کلید** بسازید.
